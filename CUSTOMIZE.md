# zhaocun portfolio

Edit `src/content.ts` to change your name, introduction, education, focus areas, project summaries, tags and GitHub links. Project artwork is implemented in `src/portfolio.tsx`; styling is in `src/portfolio.css`. Project covers are conceptual illustrations, not product screenshots.

Run `npm install --legacy-peer-deps`, then `npm run dev`. Build with `npm run build`. Upload the contents of `dist/` to Netlify; no API keys or server setup are required. The contact button opens your GitHub profile.

Content is based on your public GitHub profile and pinned repository READMEs. No employer experience or testimonials are included. Keep `LICENSE.md`, `public/LICENSE.txt` and model attribution in `public/credits.html` when redistributing.
